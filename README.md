Entry for [One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) on make.fun: a program that writes exactly one letter to `/output/entry.txt` - the answer to the coffee-or-tea question, where A means coffee and B means tea.

The answer is **A**. Coffee: the fuel of every late-night build, every deadline met at 4 a.m.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: every run writes the same byte. It needs no network and no secrets.
